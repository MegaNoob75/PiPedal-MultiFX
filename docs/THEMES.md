# Themes

[← Back to main README](../README.md)

PiPedal MultiFX includes a Theme Manager for changing the appearance of MultiFX screens without changing PiPedal musical state.

![Theme Manager](images/theme-manager.png)

## Opening the Theme Manager

Open:

```text
MFX
→ Settings
→ Theme
```

## Built-in Themes

MultiFX includes a large built-in theme library.

Selecting a theme previews its colors before it is made active.

## Set Theme

Use:

```text
SET THEME
```

to activate the selected or previewed theme.

## Custom Themes

The Customize panel provides editable roles including:

- Background
- Panel
- Panel Alt
- Navigation
- Navigation Text
- Navigation Surface
- Selected
- Selected Surface
- Selected Text
- Text
- Muted
- Border
- Danger

Use:

```text
SAVE CUSTOM
```

to save a customized theme.

## Import and Export

The Theme Manager includes:

```text
IMPORT
EXPORT
```

Use these to transfer theme data between browsers/installations or keep a backup of a custom design.

## Revert

Use:

```text
REVERT
```

to discard unsaved customization changes and return to the previous theme state.

## Per-Device Behavior

Themes are presentation state and are intentionally local to the browser/device. A floor-unit touchscreen and a desktop browser can therefore use different themes while controlling the same PiPedal musical state.

See [MultiFX-UI Settings](MULTIFX_UI.md) for shared-versus-local behavior.
