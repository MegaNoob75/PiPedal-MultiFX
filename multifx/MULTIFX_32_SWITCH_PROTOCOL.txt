PiPedal MultiFX — Physical Switch Protocol
===========================================

Maximum supported physical switches: 32

MIDI mapping:
  SW1  = CC40
  SW2  = CC41
  ...
  SW8  = CC47
  SW9  = CC48
  SW10 = CC49
  SW14 = CC53
  ...
  SW32 = CC71

Press values:
  MIDI CC value >= 64 = press
  MIDI CC value < 64  = release

Your existing 8-switch controller firmware does NOT need to change.

Example additions for a 14-switch controller:

  CCButton sw9  {PIN_SW9,  {48, CHANNEL_1}};
  CCButton sw10 {PIN_SW10, {49, CHANNEL_1}};
  CCButton sw11 {PIN_SW11, {50, CHANNEL_1}};
  CCButton sw12 {PIN_SW12, {51, CHANNEL_1}};
  CCButton sw13 {PIN_SW13, {52, CHANNEL_1}};
  CCButton sw14 {PIN_SW14, {53, CHANNEL_1}};

Continue sequentially through CC71 for SW32.

Browser transport used internally:
  SW1..SW9    -> keyboard 1..9
  SW10        -> keyboard 0
  SW11..SW32  -> F1..F22

The end user does not need to know or configure the keyboard mapping.
Controller Settings works with physical switch numbers 1..32.
